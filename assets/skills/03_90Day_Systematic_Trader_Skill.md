# 90-Day Systematic Trader Skill

## Best fit
- Trader transitioning from discretionary to process-driven execution.
- Horizon: swing trades over weeks to months.

## Market behavior assumptions
- High-probability setups are rare and cluster around confirmation.
- Process quality compounds faster than prediction quality.

## Essential rules
1. Trade only triple-confirmation setups.
2. Place buy and stop-loss simultaneously.
3. Risk <= 1% of portfolio per position.
4. Build and maintain watchlist with explicit setup metadata.
5. Do weekly review protocol without fail.

## Risk guard rails
1. Stop-loss calibrated to volatility, not fixed percent.
2. No trade if stop placement is unclear.
3. No averaging down in broken setups.
4. Maximum active positions must match monitoring capacity.

## Pattern recognition checklist
1. Volume spike >= 300% versus baseline.
2. Sideways heartbeat base present.
3. Breakout close above resistance.
4. Moving-average slope upward.
5. Fundamental catalyst present (record quarter/inflection).

## Execution protocol
1. Week 1-4: infrastructure and pattern literacy.
2. Week 5-8: paper trading and sizing calibration.
3. Week 9-12: smallest live size with full protocol.
4. Track win rate, average gain/loss, rule adherence.
