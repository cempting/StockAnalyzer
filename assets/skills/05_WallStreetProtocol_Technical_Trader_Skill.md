# Wall Street Protocol Technical Trader Skill

## Best fit
- Rule-driven breakout trader using multi-pillar confirmation.
- Horizon: short-to-medium swing windows.

## Market behavior assumptions
- Valid breakouts require trend, structure, relative strength, and volume agreement.
- One broken pillar increases false-breakout risk.

## Essential rules
1. All 4 entry pillars must be true.
2. Any 1 exit trigger enforces sell discipline.
3. Position size is risk-budget-driven, never conviction-driven.
4. Avoid pre-breakout anticipation entries.

## 4-pillar entry checklist
1. Trend confirmation: price aligned with rising key averages.
2. Relative strength confirmation: outperforming benchmark.
3. Base quality: clear, non-chaotic consolidation.
4. Volume confirmation: expansion on breakout day.

## Risk guard rails
1. Initial stop must sit beyond normal volatility noise.
2. No trade if risk/reward < 2:1 on planned structure.
3. Max simultaneous correlated trades is limited.
4. Mandatory cool-down after sequence of losses.

## Pattern recognition checklist
1. Flat-top or constructive cup/handle-like base.
2. Tightening volatility before breakout.
3. Rising relative-strength line ahead of price breakout.
4. Expanding volume on breakout candle.

## Execution protocol
1. Pre-market: prep only valid setups.
2. Entry: trigger + stop + size in one workflow.
3. Management: trail by structure, not emotions.
4. Exit: strict protocol; no post-hoc negotiation.
