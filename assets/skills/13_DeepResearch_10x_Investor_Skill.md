# Deep-Research 10x Investor Skill

## Best fit
- Concentrated investor searching for rare asymmetric multi-bagger setups.
- Horizon: multi-year with strict thesis discipline.

## Market behavior assumptions
- Extreme winners often emerge from long bases plus fundamental acceleration plus catalyst.
- Most candidates fail; selectivity is the edge.

## Essential rules
1. Require 3-step checklist: base, business momentum, catalyst.
2. Enter only when spring-effect structure is valid.
3. Build thesis with explicit disconfirming evidence.
4. Keep position sizing conservative despite upside potential.

## Risk guard rails
1. Initial exploratory size first; add only on confirmation.
2. Thesis-break conditions documented before entry.
3. Concentration limits respected despite conviction.
4. Avoid story-only names without measurable traction.

## Pattern recognition checklist
1. Multi-month to multi-year sideways base.
2. Business momentum: improving earnings/revenue quality.
3. Catalyst: event capable of rerating valuation.
4. Relative strength improvement before broad recognition.

## Execution protocol
1. Build deep dossier for each candidate.
2. Map catalyst timeline and invalidation points.
3. Use phased adds only after milestones pass.
4. Re-underwrite thesis each quarter.
